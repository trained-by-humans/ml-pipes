# ml-pipes-core

Core runtime, validation, tracing, inspection, CLI, and standard operators
for `ml-pipes`.

## Public Modules

- `ml_pipes.core`
- `ml_pipes.standard`
- `ml_pipes.validation`
- `ml_pipes.tracing`
- `ml_pipes.collectors`
- `ml_pipes.factory`
- `ml_pipes.benchmark`
- `ml_pipes.inspection`

## Install

```bash
pip install ml-pipes-core
pip install 'ml-pipes-core[inspection]'
pip install 'ml-pipes-core[otel]'
```

See [`docs/PACKAGES.md`](../../docs/PACKAGES.md) for the full package matrix
and umbrella extras.
